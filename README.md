# Golf Shot Tracker v3

Enter the distance remaining BEFORE each shot.

Example:
- Hole = 380m
- Shot 1 Driver: enter 380m remaining
- Shot 2 7I: enter 200m remaining
- Driver = 380 - 200 = 180m
- Next club distance is calculated the same way.

When a hole is finished, the last shot is treated as the holed-out shot and uses its recorded remaining distance as its shot distance.
